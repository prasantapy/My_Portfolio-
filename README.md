# Personal Portfolio Website

## Overview

This is my personal portfolio website developed using HTML, CSS, and Bootstrap. The website showcases my skills, projects, education, certifications, and contact information.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Docker
* Nginx

## Features

* Responsive design
* About Me section
* Skills section
* Projects section


## Docker Setup

### Build the Docker Image

```bash
docker build -t myhtmlapp .
```

### Run the Container

```bash
docker run -d -p 80:80 --name htmlcontainer myhtmlapp
```
