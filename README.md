## 📖 Overview

Welcome to my personal portfolio website! This project is a fully responsive, containerized web application built to showcase my skills, projects, educational background, and certifications. It serves as a digital resume and a centralized hub for my professional identity.

## ✨ Features

* **📱 Fully Responsive Design:** Optimized for seamless viewing across desktops, tablets, and mobile devices using Bootstrap 5.
* **👨‍💻 About Me Section:** A brief introduction to my background and career goals.
* **🛠️ Skills Showcase:** A visual representation of my technical toolkit (Python, FastAPI, Docker, AWS, etc.).
* **📂 Projects Gallery:** Highlights of my recent work and coding projects.
* **📜 Certifications:** A dedicated space detailing my professional qualifications.

## 🧰 Technologies Used

* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Deployment & Hosting:** Docker, Nginx
